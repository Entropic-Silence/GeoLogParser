# Public dataset metadata

This directory publishes lightweight dataset cards only. Formal interval
manifests, split IDs, hashes, evidence tiers, and licence-review status are
versioned in `datasets/manifests`, `datasets/splits`,
`datasets/data_registry.yaml`, and `datasets/source_verification_ledger.yaml`.

Original PDFs and page images are not committed merely because they were used
internally. A source file is publishable only after item-level redistribution
rights and linkage/privacy risk are both resolved. Where redistribution remains
ambiguous, the repository provides the source URL, file hash, derived reference
when permitted, and recomputation scripts instead.
