# Canonical artwork fonts

The Paper 4 vector artwork embeds the official DejaVu Sans 2.37 regular and
bold fonts. They are tracked here so the canonical figure PDFs rebuild with
the same font programs on Windows and Ubuntu instead of depending on host
fonts.

- `DejaVuSans.ttf`: `7da195a74c55bef988d0d48f9508bd5d849425c1770dba5d7bfc6ce9ed848954`
- `DejaVuSans-Bold.ttf`: `e6476c1b80502924294eed40894c5b18e06c181444ca953e5334262df9c27724`
